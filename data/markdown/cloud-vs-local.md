刚把酒馆跑起来的人,十有八九都会卡在这个选择上：

> "我到底该用云端版酒馆，还是自己本地部署？"

这两种方式没有绝对优劣，**适不适合**才是关键。本文从 4 个维度做完整对比。

## 两种方式分别是什么

### 云端版部署
别人已经把 SillyTavern 部署在服务器上，你打开浏览器就能用。

- 开箱即用，不需要装环境
- 不受设备限制（手机、平板、电脑都能用）
- 能力受限于运营方提供的功能

### 本地部署
自己在电脑（Windows / Mac / Linux）或自己服务器上装 SillyTavern。

- 完全自由，所有功能可用
- 数据完全在自己手里
- 要懂一点点命令行

## 维度 1：成本

| 项目 | 云端 | 本地 |
|---|---|---|
| 软件本体 | 免费或低费 | 完全免费 |
| 服务器 | 运营方承担 | 自己承担 |
| AI 模型费用 | **都得自己出** | **都得自己出** |
| 时间成本 | 几乎为零 | 第一次 1~3 小时 |

<div class="warn">

**最常见误区**：本地部署 ≠ AI 免费用。无论云端还是本地，AI 模型的钱都得花。本地能省的只是"前端服务费"，不是 AI 调用费。

</div>

## 维度 2：稳定性

**云端**：运营方维护，可用性通常较高；但运营方跑路、被封、限流你完全没办法。

**本地**：自己说了算没人能停掉你；但自己电脑/网络/硬盘出问题就全没了。

> 真相：稳定性是个对赌——**信运营方人品 vs 信自己运维能力**。

## 维度 3：上手难度

| 操作 | 云端 | 本地 |
|---|---|---|
| 第一次打开 | 浏览器输入网址 | 命令行运行脚本 |
| 安装时间 | 0 分钟 | 30 分钟~2 小时 |
| 装插件 | 取决于运营方 | 想装啥装啥 |
| 同步多设备 | 自动 | 需要折腾 |
| 备份 | 看运营方 | 自己复制 |
| 更新版本 | 运营方推送 | 自己 git pull |

完全不想碰命令行→云端最舒服。乐意花一晚上折腾一次→本地能换长期自由。

## 维度 4：自由度与定制

| 能力 | 云端 | 本地 |
|---|---|---|
| 装第三方扩展 | 大多受限 | 完全自由 |
| 改源码 | 不可能 | 没问题 |
| 用最新版 | 看运营方 | 自己说了算 |
| 数据完全私有 | 难保证 | 完全可控 |

## 决策表

| 你是这样的人 | 推荐 |
|---|---|
| 第一次接触，想先试试水 | 云端 |
| 不想花时间装环境 | 云端 |
| 经常换设备 | 云端 |
| 苹果手机用户（无法本地） | 云端 |
| 喜欢折腾，爱装插件 | 本地 |
| 看重隐私，不想数据放别人那 | 本地 |
| 一周用不了几次 | 云端 |

## 推荐组合方案

我自己两种都用过——给一个不负责任的建议:**先用云端跑顺,再决定要不要折腾本地**。

实际上**很多老玩家两种都用**：

1. 平时用云端：通勤、手机、临时聊
2. 重度场景本地：长篇剧情、需要装特殊插件
3. 数据手动同步：定期把云端聊天记录导出本地备份

<div class="tip">

**新人路线建议**:先选门槛低的方式跑通完整流程(导入卡、配 API、聊一次完整对话),熟悉后再决定要不要折腾另一种。

如果你彻底不想碰命令行,挑一家中文圈在运营的免部署服务直接用是更轻松的入口,比如 [SillyTavern Pro](https://sillytavern.one/) 这类。如果你想完全自己控制,跳到下面的本地部署快速教程。

**怎么挑靠谱的在线版运营方**(避免跑路、丢卡):

- 运营时长 ≥ 半年(避免短命跑路站)
- 提供数据导出功能(防止以后想迁移走时没法走)
- 社群活跃、能找到客服反馈
- 价格不要远低于行业均值("无限免费"通常有坑)
- 公开告知数据存储位置和保留策略

## 本地部署快速教程(流水版)

如果你已经决定走本地,下面是流水版,3 步搞定。各种报错对应方法、Windows / macOS / Linux 三平台完整步骤、卸载 / 更新 / 迁移等详见 **[本地部署完整教程](/getting-started/local-install/)**。

```bash
# 1. 装 Node.js 20+ 和 Git(Windows 去 nodejs.org 下 .msi)

# 2. 拉代码 + 装依赖 + 启动
git clone https://github.com/SillyTavern/SillyTavern.git
cd SillyTavern
npm install --no-audit --no-fund
node server.js

# 3. 浏览器打开 http://localhost:8000
```

国内 npm 慢可以先换镜像:

```bash
npm config set registry https://registry.npmmirror.com
```

报错请直接看 [本地部署完整教程](/getting-started/local-install/) 的对照表。

</div>

## 常见问题

**Q：云端数据安全吗？**
取决于运营方。看 3 点：是否长期稳定、是否有备份说明、是否提供数据导出。

**Q：本地部署会不会很慢？**
酒馆本身极轻量，慢的不是它，是你接的 AI 模型。

**Q：手机能本地部署吗？**
原则上可以（Android Termux），但折腾成本远高于云端。**手机用户强烈推荐云端**。

## 总结

> **新手优先云端，老玩家两边都有**。不要把这件事神化——你最终能聊多深、玩多远，取决于你的角色卡、预设、模型，而不是装在云端还是本地。
