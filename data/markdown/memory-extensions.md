被 AI 一句"昨天的事记不清了"打回原形的玩家不在少数。

聊到 60 楼,角色把上周一的约会说成今天早上;送过的礼物凭空消失;NPC 的关系倒置——这不是模型变差,是**上下文窗口装不下那么多东西**了。

记忆类扩展就是为了解决这个问题。但圈子里现在至少有 4 个主流方案,各自做法完全不同,**装错一个不仅没用还会拖慢生成**。

这一篇横评 4 家、给你一个 5 步决策树,看完知道自己该装哪个。

## TLDR

**4 家记忆方案分别擅长什么**:

- **结构化时间锚 + 全功能**:适合长篇沉浸玩家,功能最齐但配置项多
- **结构化表格记忆**:适合喜欢"看见数据"的玩家,可视化最强
- **AI 自动总结**:适合不想折腾、追求"装上就好"的玩家
- **轻量化自动摘要**:适合 Token 敏感、需要后台压缩的场景

**铁律**:**4 家功能有重叠,只装一个**,装多个会互相打架。

## 关键事实

- 4 家全部基于 <span>SillyTavern</span> 原生功能扩展,核心都是"压缩历史 + 注入摘要"
- 都需要先装 <span>SillyTavern</span> 本体的近期版本,部分功能依赖[酒馆助手](/extensions/tavern-helper/)
- 中文社区维护,作者活跃,文档较完整
- **都不消耗你的会员/积分**,纯前端扩展,本地运行
- 装错一个会"打架":两个插件同时给同一段历史做总结,会产生重复 prompt

## 4 家记忆插件横评(按特点)

### 方案 A:Horae - 时光记忆

> **作者**:SenriYuki  ·  **仓库**:[github.com/SenriYuki/SillyTavern-Horae](https://github.com/SenriYuki/SillyTavern-Horae)

**核心特点**:用结构化的时间锚点给 AI 装上"记忆账本"。

它把一次对话拆成若干个事件、地点、人物状态,各自带时间戳。AI 之后被注入这些结构化记忆时,自动算出"昨天"、"上周三"、"上个月 15 号"这种相对时间——这是它最特别的地方。

**特别擅长**:

- **场景记忆**:同一个酒馆,上回有壁炉这回不能凭空消失
- **服装锁定**:每个角色当前穿什么是锁住的,不会突然换装
- **物品系统**:带唯一编号、分级别(一般/重要/关键),数量变化"5 斤→4 斤"自动解析
- **NPC 关系网**:谁欠谁钱、谁讨厌谁,变化时才输出,无变化零 Token
- **RPG 模式**:西幻/修真/战斗向卡可开,有血条技能状态条 HUD

**短板**:

- **配置项多**:首次设置容易迷,需要花时间读文档
- **依赖向量索引时**:首次用要下载 30-60MB 模型缓存
- **对短篇日常向不必要**:几十楼就能讲完的剧情用它属于杀鸡用牛刀

**适合谁**:认真跑长篇 RP 的玩家、跑团、玩西幻/修真。

---

### 方案 B:酒馆记忆增强(表格记忆)

> **作者**:muyoou  ·  **仓库**:[github.com/muyoou/st-memory-enhancement](https://github.com/muyoou/st-memory-enhancement)  ·  **国内镜像**:[gitee.com/muyoou/st-memory-enhancement](https://gitee.com/muyoou/st-memory-enhancement)

**核心特点**:把记忆做成一张张可编辑的表格,AI 自动填、用户可以手改。

它不像 Horae 那样关心"昨天还是上周",而是关心"**当前世界状态是什么**"——角色关系、物品清单、关键事件,全部表格化。每个表格可以自定义列(像 Excel 一样),AI 自动按规则填。

**特别擅长**:

- **可视化最强**:打开一个面板就能看到当前所有记忆,像数据库
- **可编辑**:不满意 AI 填的内容,直接点表格手改,下次注入就用你改的
- **模板可分享**:做好的表格结构能导出 JSON,社区互通
- **分步操作**:可以配主副 API,主 API 跑剧情,副 API 跑表格整理

**短板**:

- **注入是全表覆盖**:不像 Horae 那样"变化驱动",每次都重新注入完整表格
- **Token 消耗稍大**:表格内容长了,每楼都重新发整张表
- **需要适应近期版本**:旧版酒馆部分功能不可用

**适合谁**:喜欢"看见数据"的玩家、跑表格化系统(职业卡 / 属性卡)、做创作者想分享模板。

---

### 方案 C:Amily2 号助手(总结向)

> **作者**:诗与酒  ·  **类型**:总结工具,定位偏轻量

**核心特点**:专注"总结"这一件事——不做时间锚、不做表格,只把旧历史压成一段段总结塞回上下文。

它不像 Horae / 记忆表格那么"重",安装即用,默认参数就有效果,适合不想花时间折腾的玩家。

**特别擅长**:

- **上手最快**:几乎零配置
- **专注总结**:不掺杂其他功能,就一件事做到位
- **文档详细**:作者写了完整教程

**短板**:

- **功能单一**:不会管角色服装、不会记 NPC 关系、不会做物品系统
- **适合场景较窄**:不想要"全功能",只想"自动总结"的人合适

**适合谁**:不想折腾、追求"装上就好"的玩家;短篇/中篇剧情玩家。

> 教程文档由作者发布,具体地址请在中文社群中搜索"Amily2 号助手"获取最新版本。

### 方案 D:全自动总结脚本(酒馆助手脚本)

> **二次开发**:90  ·  **原作者**:人世如潮  ·  **仓库**:[github.com/EphemeralAlien/AutoSummarizer](https://github.com/EphemeralAlien/AutoSummarizer)  ·  **类型**:JS 脚本(不是独立扩展)

**核心特点**:它不是扩展,是一个跑在[酒馆助手](/extensions/tavern-helper/)里的 JS 脚本——所以**必须先装酒馆助手**。

**特别擅长**:

- **后台静默运行**:你正常聊,它在后面悄悄压
- **轻量**:只是脚本,不增加扩展数量
- **可二改**:基于开源源码,会写 JS 的玩家可自定义触发条件

**短板**:

- **依赖酒馆助手**:没装底座等于零
- **配置藏得深**:需要懂酒馆助手的"脚本库"概念
- **没有 GUI 面板**:全靠提示词控制

**适合谁**:已经装了酒馆助手、不想再装独立扩展、追求极简。

## 我该装哪个?5 步决策树

按这 5 个问题往下走,3 分钟内有答案。

### 第 1 步:你跑的是日常向还是长篇 RP?

- **日常向 / 短篇**(每次对话 < 50 楼):**Amily2** 或 **不装记忆插件**就够,过早上重型方案是负担
- **长篇 RP**(动辄上百楼,跨越数天/数周):继续往下走

### 第 2 步:你跑团 / 西幻 / 战斗向吗?

- **是**(有血条、技能、属性这种概念):**Horae**(它的 RPG 模式 + 物品系统是为这个设计的)
- **否**:继续往下走

### 第 3 步:你想"看见数据"还是"AI 自动管"?

- **看见数据**(喜欢点开表格看当前状态、想手动调):**记忆表格**(可视化最强)
- **AI 自动管**(不想动,装完就跑):继续

### 第 4 步:你已经装了酒馆助手吗?

- **已装**:**全自动总结脚本** 是最轻量选项,直接导入 JS 就行
- **没装**:回去先看[酒馆助手](/extensions/tavern-helper/)那篇,**很多扩展都依赖它**

### 第 5 步:确认你的 Token 预算

- **预算紧**(用免费 API / 限速频繁):优先 **Horae**(变化驱动) 或 **全自动总结**(后台压)
- **预算宽**(付费 API / 高额度):4 选 1 都行

> ⚠️ **再次强调**:无论选哪个,**只装一个**。两个记忆插件同时跑会互相打架——它们都试图给同一段历史做总结,生成的 prompt 会重复甚至冲突。

## 实战场景:不同玩法装哪个

**场景 1:现代日常 / 都市恋爱向**

- 推荐:**Amily2** 或 **不装**
- 理由:剧情节奏快、世界观简单,不需要复杂的记忆系统。Amily2 装上就跑,够用。

**场景 2:西幻 / 修真 / 战斗 RPG**

- 推荐:**Horae**
- 理由:它的 RPG 模式专为这个设计,血条/技能/状态/物品全有。其他方案做不到这个深度。

**场景 3:百万字长篇小说创作**

- 推荐:**记忆表格** 或 **Horae(开自动摘要 + 向量记忆)**
- 理由:几十万字后细节会全丢,需要专门的"外脑"找回历史片段。两家都有这个能力,看你喜欢"表格化"还是"时间线化"。

**场景 4:跑团(TRPG)**

- 推荐:**记忆表格** + 自定义模板
- 理由:跑团需要追踪角色卡、物品栏、NPC 关系,表格是最直观的方式。

**场景 5:已装酒馆助手 + 想极简**

- 推荐:**全自动总结脚本**
- 理由:不增加扩展数量,后台压历史够用了。

## 5 个常见误区

### 1. "装了就忘"——以为装上就万事大吉

记忆插件**不会无中生有**。如果你的剧情没明确写"角色穿了校服",它无法记住。它的作用是**保住已经写出来的东西不丢**,不是凭空补设定。

### 2. 同时装 2-3 个想"全部都用"

**会打架**。两个插件都试图给同一段历史做总结,产生的 prompt 互相重复甚至冲突,效果反而比只装一个差。**选一个,坚持一周再评价**。

### 3. 不肯花 30 分钟读文档

记忆类插件**不是装完就立刻有效果**——你需要懂它怎么"挑选"、"压缩"、"注入"。各家文档都不长,认真读一遍能省后面 10 倍调试时间。

### 4. 期望"完美记忆 = 永不忘"

**不存在**。AI 受上下文窗口限制,任何记忆插件本质都是"挑重点扔进 prompt",不可能 100% 还原历史。学会**接受偶尔失忆**比追求完美更重要。

### 5. Token 预算没算清楚就装

记忆插件会增加每楼的 prompt 长度——表格记忆可能每楼多 1000+ token。**先看你的 API 单价 + 预算,再决定要不要上重型方案**。

## FAQ

<details>
<summary>Q1:记忆插件会让 AI 变笨吗?</summary>

不会让"AI 模型本身"变笨,但会改变它的输出习惯——因为每楼 prompt 多了一段"过去发生了什么"的总结,模型注意力会被分散到这部分。所以好的记忆插件都讲究**变化驱动 / 按需注入**,不要每次塞一大堆。
</details>

<details>
<summary>Q2:免费 API 用户能用吗?</summary>

可以,但要选 **Token 消耗低的方案**。Horae 的"变化驱动"和全自动总结脚本对免费 API 友好。记忆表格在免费 API 下容易超额度。
</details>

<details>
<summary>Q3:已经聊了 200 楼才装,会有效果吗?</summary>

部分插件(如 Horae)支持"AI 智能摘要"——一键扫描历史楼层,自动生成完整时间线。所以**不晚**,但你要让它跑一次"补全旧档案"才行,纯靠新增不会回去翻旧账。
</details>

<details>
<summary>Q4:换电脑 / 换浏览器,记忆数据会丢吗?</summary>

数据存在 <span>SillyTavern</span> 的本地存储里,**换浏览器会丢**(除非你导出再导入)。建议在新设备装好对应插件后,导入备份的世界书 / 表格 JSON。
</details>

<details>
<summary>Q5:可以同时用记忆插件 + 世界书吗?</summary>

可以,而且**强烈建议**。世界书管"固定不变的设定"(地点、组织、规则),记忆插件管"动态变化的状态"(角色关系、物品、剧情)。两者职能不冲突,组合使用最强。看[世界书入门](/presets-lorebooks/lorebook-basics/)和[长对话失忆终极方案](/advanced/long-chat-summary/)。
</details>

<details>
<summary>Q6:作者跑路了我的数据怎么办?</summary>

这些插件都是开源的,代码在你本地。即使作者不更新了,只要 <span>SillyTavern</span> 本身没大改,扩展能继续跑。数据导出 JSON 也是各家标配,迁移到其他工具也不难。
</details>

<details>
<summary>Q7:推荐用副 API 跑摘要吗?</summary>

如果你的主 API 是高端模型(Opus 类),**强烈推荐**配一个低成本副 API(DeepSeek / Gemini Flash)专门跑摘要。原因:摘要任务对智能要求不高,但很费 token,用便宜模型省钱不少。记忆表格和 Horae 都支持双 API。
</details>

<details>
<summary>Q8:实在不会选,有"安全选择"吗?</summary>

如果你完全不知道选哪个,**先装 Horae**——它功能最全,即使大部分功能没用上,基础的服装锁定 + 物品系统也比不装强。如果嫌它重,再降级到 Amily2。
</details>
