"为什么我装的 XX 扩展报错?"

群里这个问题每周出现至少十次。
答案 80% 是同一个:**没装酒馆助手**。

这一篇讲清楚:酒馆助手是什么、为什么是"必须装的第一个扩展"、怎么装、出问题怎么排。

我见过装了一堆扩展报错的人,**十有八九是没装这个底座**。

## 它到底是什么

字面意思:它本身**几乎不做任何具体功能**。

那它干嘛用?

它是一个**底座**——给其他扩展提供 API 和能力。打个比方:
- 想吃饭你得有桌子
- 想用酷扩展你得有酒馆助手

它具体提供:
- 让其他扩展能跑 JavaScript
- 让其他扩展能读写酒馆里的数据
- 让其他扩展能创建按钮、菜单、弹窗
- 让其他扩展能和 AI 直接交互(发送指令、解析回复)

没有它,记忆增强、表格记忆、文生图、QR 助手……一个都跑不起来。

## 怎么装

打开酒馆 → 顶部「**扩展**」图标(像四个方块的那个) → 「**安装扩展**」按钮。

弹窗里粘贴下面**任意一个**仓库地址(GitHub 在国内经常超时,**强烈建议直接用 GitLab 镜像**):

**GitHub 主仓库**(国外网络):
https://github.com/N0VI028/JS-Slash-Runner.git

**GitLab 镜像**(国内网络推荐):
https://gitlab.com/novi028/JS-Slash-Runner

两个地址内容完全一致,任选其一即可。

注意:
- 选「**Install for all users**」(给所有用户装,即使你只一个人用也选这个)
- 网速不好可能装到一半失败,**重试一次**
- 装完后扩展列表里会出现 Tavern Helper 的勾选项,**必须勾上启用**

## 装完后第一件事:检查能不能用

最简单的检测方法:
1. 打开任意一个角色对话
2. 在输入框里输入(不要回车):`/th help`
3. 如果回车前看到自动补全或弹了一行提示,说明它启动了

或者打开浏览器 F12 → Console,看有没有 `Tavern Helper loaded` 或类似日志。

## 常见安装失败

### Git URL 拷错了
有些人复制时少了 .git 后缀,有些人多了空格。
**重新精确复制一次**,粘贴前删干净输入框。

### 网络问题
酒馆从 Git 拉代码,中转/国内网络可能不通。
**开梯子**,或者用国内镜像。

### "Module not found" 错误
酒馆助手依赖某些 Node 包,如果你是本地部署、Node 版本太老,会报这个。
**升级 Node 到 18+**。

### 装了但没启用
最容易忽略。装完不自动启用,要去扩展面板**手动勾**。

## 高级用法:你可能不知道的能力

酒馆助手不光是"被别的扩展依赖"。它本身有些功能挺好用:

### 1. 跑自定义 JS
在角色卡或预设里,你可以放一段 JS 脚本,**自动执行**。
- 例如:消息发送前自动给你的输入加上"作为玩家,我"开头
- 例如:消息接收后自动隐藏某些关键词

### 2. 自定义 Slash 命令
你可以定义自己的 `/xxx` 指令,实现快速操作。
- `/summary` → 自动总结最近 30 楼
- `/save` → 备份当前对话
- `/mode dark` → 切换主题

### 3. 与 AI 双向交互
最强的一点:可以让你的扩展**在 AI 回复后做处理**。
- AI 回复 → 提取里面的"好感度+1" → 自动更新一个表格
- AI 回复 → 检测某个关键词 → 触发文生图

这就是"记忆表格"、"自动总结"等高级扩展的实现基础。

## 我个人的推荐:必装顺序

完整必装清单见 [《必装扩展 TOP 10》](/extensions/top-10/),这里只列前几个。

1. **酒馆助手 / Tavern Helper(JS-Slash-Runner,绝对的第一个)**
2. 表格记忆 / 记忆增强
3. QR 助手
4. 翻译 / TTS / 其他按需

> **澄清一个常见误解**:很多新手以为「酒馆助手」和「JS-Slash-Runner」是两个不同扩展,其实它们是**同一个项目**——JS-Slash-Runner 是仓库名,酒馆助手是中文社区习惯叫法。装一次就够。

装完前 3 个,你的酒馆已经从"基础聊天工具"进化成"半个游戏框架"了。

## 一些容易踩的坑

### 酒馆助手不会自动更新
作者更新版本时,你**得自己重新装一次**(或在扩展面板点更新)。

### 多个版本可能冲突
有些扩展是为旧版酒馆助手写的,装在新版上会报错。
版本不兼容时,看扩展作者的说明。

### 删了不彻底
卸载扩展时,有些残留文件不会清。
**最稳的方法**:停酒馆 → 直接删 `public/scripts/extensions/third-party/JS-Slash-Runner`(目录名取决于你装的版本,可能是 `JS-Slash-Runner` 也可能是其他,看实际) 文件夹 → 重装。

## 一句结语

酒馆装好之后第一件事不是导卡、不是配预设,是**装酒馆助手**。
你以后做的任何高级操作,99% 都要依赖它。
